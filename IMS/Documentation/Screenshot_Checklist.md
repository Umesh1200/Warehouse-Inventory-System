# IMS Screenshot Checklist for Final Report

Use this checklist to ensure all key modules and functionalities are documented.

## 1. Authentication & Security
- [ ] **Login Page**: Show the professional login interface with validation.
- [ ] **Access Denied**: Show the "Access Denied" page when a Staff user tries to access `/Admin/Settings`.
- [ ] **User Role UI**: Side-by-side view showing the sidebar differences between Admin (full) and Staff (limited).

## 2. Core Dashboards
- [ ] **Admin Dashboard**: Highlight the summary cards and Low Stock alerts.
- [ ] **Inventory Overview**: Show the real-time stock levels across different warehouses and shelves.
- [ ] **Audit Trail**: Demonstrate the stock movement history with active filters applied.

## 3. Inward Workflow (Purchasing)
- [ ] **Purchase Orders**: List of confirmed and pending POs.
- [ ] **Goods Receiving**: The form for recording inward quantity and batch numbers.
- [ ] **QC Check**: Submission of quality inspection results.
- [ ] **Putaway Tasks**: Finalizing movement of goods from staging to permanent shelf storage.

## 4. Outward Workflow (Sales)
- [ ] **Sales Orders**: Overview of orders with different statuses (Draft, ReadyToPick, etc.).
- [ ] **Picking & Packing**: Warehouse staff view for picking items and finalizing packaging.
- [ ] **Dispatch Tracking**: Confirmation of shipment and recording tracking numbers.

## 5. Manufacturing Support
- [ ] **Production Planning**: List of approved production runs.
- [ ] **Material Issue/Return**: Logging raw material consumption and returning excess items.
- [ ] **Finished Goods Receipt**: Recording newly manufactured products into inventory.

## 6. Administration & Setup
- [ ] **Users & Roles**: Management of system users and their active statuses.
- [ ] **Warehouse Setup**: Multi-level hierarchy visualization (Floors, Rooms, Racks).
- [ ] **System Settings**: Global company info and inventory threshold configuration.

## 7. Reporting & Data
- [ ] **CSV Export**: Screenshot of the exported Audit Log file in Excel or a text editor.
- [ ] **Stock Movement Details**: Human-readable remarks showing dynamic user attribution (e.g., "Confirmed by Arjun Thapa").
